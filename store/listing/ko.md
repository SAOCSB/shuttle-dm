# 스토어 정보 — 한국어

**이름**(패키지에서 자동 입력): Shuttle DM – 다운로드 매니저

**요약**(패키지에서 자동 입력):
다중 연결로 빠르게 받고 이어받기를 지원하는 다운로드 매니저. 웹 동영상(MP4, M3U8) 저장, 오디오·비디오 병합, 웹페이지 저장, 일괄 다운로드.

**자세한 설명**(두 줄 사이의 텍스트를 붙여 넣으세요):

---
Shuttle DM은 브라우저 안에서만 동작하는 빠른 다운로드 매니저입니다.

다중 연결 다운로드
• 큰 파일을 여러 부분으로 나눠 여러 연결로 동시에 다운로드합니다.
• 먼저 끝난 연결은 가장 많이 남은 부분의 뒤쪽 절반을 넘겨받습니다. 그래서 마지막에 느린 연결 하나만 남는 일이 없습니다.
• 언제든 일시 중지하고 다시 이어서 받을 수 있습니다. 네트워크가 끊기거나 브라우저가 멈추거나 다시 시작해도 이어서 다운로드합니다.

웹 동영상
• 페이지에서 재생되는 동영상과 오디오를 감지합니다. MP4, WebM 등의 파일, HLS(M3U8) 스트림, 따로 전송되는 오디오 트랙과 비디오 트랙을 지원합니다.
• 동영상 위에 마우스를 올리고 ‘이 동영상 다운로드’를 클릭하거나, 도구 모음 팝업에서 선택하세요.
• 적응형 스트림은 화질을 고를 수 있습니다. HLS 스트림은 재인코딩 없이 표준 MP4로 저장되고, 따로 받은 오디오·비디오 트랙은 하나의 MP4로 병합됩니다.
• HLS 라이브 방송을 중지할 때까지 녹화할 수 있습니다.

더 많은 기능
• 브라우저 자체 다운로드(압축 파일, 설치 파일, 문서 등)를 넘겨받아 더 빠르게 받습니다. 대상 파일 형식과 최소 크기, 제외할 사이트를 설정할 수 있습니다.
• 페이지 전체를 MHTML 파일 하나 또는 HTML로 저장합니다.
• 일괄 다운로드: 페이지나 선택 영역의 모든 링크, 이미지, 오디오, 동영상을 나열하며 형식별 필터와 와일드카드 검색을 지원합니다.
• 분류, 검색, 정렬, 단축키를 지원하고 연결마다 진행 상황을 실시간으로 보여 주는 다운로드 매니저.
• 전체 속도 제한, 대기열, 파일 형식별 폴더 저장, 알림, 다크 모드.
• 지원 언어: English, 简体中文, Français, 日本語, 한국어.

개인정보 보호
모든 작업은 사용자의 컴퓨터에서 이루어집니다. 계정, 통계 수집, 광고가 없으며 개발자나 제3자에게 아무것도 보내지 않습니다. 소스 코드는 GitHub에 공개되어 있습니다: https://github.com/SAOCSB/shuttle-dm

참고
• 저장할 권리가 있는 콘텐츠만 다운로드하고, 이용하는 웹사이트의 약관을 지켜 주세요.
• DRM(Widevine, FairPlay, PlayReady 등)으로 보호된 동영상은 다운로드할 수 없습니다.
• YouTube 동영상은 지원하지 않습니다.
• 브라우저는 HTTP/1.1 서버 하나에 최대 6개까지만 연결하므로 다운로드당 기본 연결 수는 6개입니다.
